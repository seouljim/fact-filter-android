# FACT FILTER 안드로이드

유튜브 앱을 보는 동안 화면 위에 반투명 창을 띄워, 영상 속 주장과 공식 원문의 대조 결과를 재생 위치에 맞춰 보여주는 앱.
분석은 AI FACT FILTER 서버가 하고, 이 앱은 "지금 무슨 영상의 어디를 보고 있는지"를 알아내 결과를 띄운다.

## 진행 단계

- [x] 1단계 유튜브 앱이 재생 정보(제목·채널·길이·재생 위치)를 알려주는지 확인 → 긴 영상은 알려주고 쇼츠는 비워서 내보냄
- [x] 2단계 서버 연결: 제목·채널·길이로 영상을 찾아 대조 결과 받아 오기
- [x] 3단계 재생 위치에 맞춰 주장과 결과 표시, 쇼츠는 공유로 확인
- [ ] 4단계 구글 플레이 내부 테스트 배포

## 설치

`main` 에 올리면 GitHub Actions 가 APK 를 만들어 **Releases → 최신 시험판**에 올린다.
휴대폰에서 `fact-filter.apk` 를 받아 설치한다. ("출처를 알 수 없는 앱 설치"를 허용해야 한다)

## 권한

| 권한 | 쓰는 곳 |
| --- | --- |
| 알림 접근 | 유튜브의 미디어 세션(재생 중인 제목·위치) 읽기. 알림 내용은 읽지 않는다 |
| 다른 앱 위에 표시 | 유튜브 위에 반투명 창 띄우기 |

## 서명 키

`app/debug.keystore` 는 업데이트 설치가 되도록 고정해 둔 시험용 키다. 배포용이 아니다.

## 서버 접근 열쇠

분석 서버는 열쇠(`x-app-key`)가 맞는 요청만 받는다. 열쇠는 저장소에 적지 않고
**Settings → Secrets and variables → Actions** 의 `APP_ACCESS_KEY` 비밀 값에서 받아 빌드에 넣는다.
서버(Vercel)의 환경변수 `APP_ACCESS_KEY` 와 같은 값이어야 한다.
